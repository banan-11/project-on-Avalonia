\# Информационная система «Фотостудия» (Photo Studio)



Курсовой проект по дисциплине «Разработка информационных систем».  

Тема: \*\*Автоматизация работы фотостудии\*\*.



\## Описание проекта



Приложение представляет собой десктопную информационную систему для управления бронированием залов и учетом заказов фотостудии. Система позволяет клиентам выбирать свободные залы на нужную дату и время, а сотрудникам — управлять списком фотографов, статусами заказов и просматривать статистику продаж.



\### Основные функции:

1\.  \*\*Авторизация пользователей\*\* с разделением ролей (Администратор, Фотограф, Пользователь/Клиент).

2\.  \*\*Каталог залов:\*\* просмотр карточек залов с описанием оборудования и фотографиями.

3\.  \*\*Бронирование:\*\* выбор даты, времени начала аренды и количества часов.

4\.  \*\*Учет исполнителей:\*\* закрепление конкретных фотографов за заказами с расчетом итоговой стоимости услуги.

5\.  \*\*Статусы заказов:\*\* отслеживание жизненного цикла заявки (Подтверждён, Отменён, Завершён).

\## Структура проекта



Проект организован по принципу разделения ответственности (MVVM-like pattern adapted for simplicity):



```text

src/

├── Assets/          # Ресурсы приложения (иконки, изображения залов)

│   └── Images/      # Файлы картинок для каталога (loft.png, studio.png...)

├── Data/            # Слой доступа к данным

│   ├── Db.cs        # Фабрика контекста базы данных (чтение connection.txt)

│   └── PhotoContext.cs # Генерируемый EF Core контекст БД

├── Models/          # Классы-модели (таблицы БД + логика отображения)

│   ├── Hall.cs      # Модель зала

│   ├── Order.cs     # Модель заказа

│   ├── User.cs      # Модель пользователя

│   ├── Photographer.cs # Модель фотографа

│   ├── Role.cs      # Справочник ролей

│   ├── Status.cs    # Справочник статусов

│   └── ModelExtras.cs # Partial-классы для переопределения ToString() и вычисляемых свойств

├── Services/        # Бизнес-логика (работает с БД через Data layer)

├── Views/           # Интерфейс (XAML разметка и code-behind)

│   ├── MainWindow.axaml # Главное окно навигации

│   ├── LoginView.axaml  # Экран входа

│   ├── CatalogView.axaml # Каталог залов

│   └── ...              # Другие страницы

├── App.axaml        # Глобальные стили и ресурсы приложения

├── Program.cs       # Точка входа

└── photoStudio.csproj # Файл проекта

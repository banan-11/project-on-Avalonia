# Информационная система «Фотостудия» (Photo Studio)Курсовой проект по МДК.01.01 «Разработка программных модулей».Тема: **Разработка информационной системы для фотостудии**.## Описание проектаДесктопное приложение для бронирования залов фотостудии и учёта заказов. Клиент выбирает зал, фотографа, дату, время и длительность; система проверяет, что зал и фотограф свободны, и рассчитывает стоимость. Сотрудники видят свой рабочий график, администратор управляет залами, фотографами и всеми заказами.### Основные функции1. **Авторизация и регистрация** с ролями: Администратор, Фотограф, Пользователь (клиент), Гость.2. **Каталог залов** — карточки с фото, оборудованием, ценой, поиском и сортировкой.3. **Бронирование** — проверка пересечений по залу и по фотографу в транзакции Serializable, показ занятого времени.4. **Расчёт стоимости** — (аренда зала + ставка фотографа) × часы; скидка 25 % на зал без заказов в прошлом месяце.5. **Статусы заказов** — Подтверждён → Завершён / Отменён (отмена сохраняет историю).6. **Управление** — залы, создание сотрудников, редактирование фотографов (только администратор).## Технологический стек* C# (.NET 10.0), Avalonia UI 12* Microsoft SQL Server, Entity Framework Core (Database First)* Git \& GitHub## Запуск1. Создайте базу `Photo` и выполните `resources/database\\\\\\\_script.sql`.2. Укажите свой сервер в `src/Photo/connection.txt`.3. Соберите и запустите `src/Photo/Photo.csproj`.Тестовые учётные записи: `admin / admin` (администратор), `smirnov / 1234` (фотограф), `ivanova / 1234` (клиент).## Структура проекта```textsrc/Photo/├── Assets/            # logo.png, picture.png (заглушка), mainPhoto.ico, Images/ — фото залов├── Data/              # Db.cs (фабрика подключений), PhotoContext.cs (EF Core)├── Models/            # Hall, Order, Photographer, User, Role, Status + ModelExtras (вычисляемые свойства)├── Services/          # Session, OrderService, CatalogService, PriceRules, HallCard, AppException├── Views/             # MainWindow (боковое меню, уведомления) и страницы:│                      # Login, Registration, Catalog, Course (бронирование), Orders, OrderDetails,│                      # StaffManagement, StaffCreation, HallsManagement; UiSupport├── App.axaml          # Цветовая схема и общие стили└── connection.txt     # Строка подключения к SQL Serverresources/├── database\\\\\\\_script.sql  # Структура БД и тестовые данные└── sources.txt          # Источники изображенийПояснительная записка.docx```

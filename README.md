# Информационная система «Фотостудия» (Photo Studio)

Курсовой проект по дисциплине «Разработка информационных систем».  
Тема: **Автоматизация работы фотостудии**.

## Описание проекта

Приложение представляет собой десктопную информационную систему для управления бронированием залов и учетом заказов фотостудии. Система позволяет клиентам выбирать свободные залы на нужную дату и время, а сотрудникам — управлять списком фотографов, статусами заказов и просматривать статистику продаж.

### Основные функции:
1.  **Авторизация пользователей** с разделением ролей (Администратор, Фотограф, Пользователь/Клиент).
2.  **Каталог залов:** просмотр карточек залов с описанием оборудования и фотографиями.
3.  **Бронирование:** выбор даты, времени начала аренды и количества часов.
4.  **Учет исполнителей:** закрепление конкретных фотографов за заказами с расчетом итоговой стоимости услуги.
5.  **Статусы заказов:** отслеживание жизненного цикла заявки (Подтверждён, Отменён, Завершён).

## Технологический стек

*   **Язык программирования:** C# (.NET 10.0)
*   **GUI-фреймворк:** Avalonia UI (Cross-platform desktop framework)
*   **База данных:** Microsoft SQL Server
*   **ORM (Object-Relational Mapping):** Entity Framework Core (Database First approach)
*   **Среда разработки:** Visual Studio 2026 / JetBrains Rider
*   **Система контроля версий:** Git & GitHub

## Структура проекта (этап завершения 2.3)

На текущем этапе реализована инфраструктура подключения к базе данных, модели таблиц, глобальные стили оформления и вспомогательные классы для работы с ресурсами (картинками) и ошибками. Логика бизнес-процессов (чтение/запись данных) будет добавлена в следующих разделах.

```text
src/Photo/                  # Корневая папка приложения (.csproj здесь)
│
├── Assets/                 # Ресурсы программы (упаковываются внутрь .exe как avares://)
│   ├── Images/             # Папка с фотографиями залов для будущего каталога
│   │   ├── loft_studio.png     # Фото лофта (пример)
│   │   ├── neon_hallway.png    # Фото неонового коридора (пример)
│   │   └── ...                 # Остальные картинки из БД
│   ├── logo.png            # Логотип приложения (для шапки окна)
│   ├── picture.png         # Заглушка "Нет фотографии" (fallback при ошибке пути)
│   └── app.ico             # Иконка исполняемого файла
│
├── Data/                   # Слой доступа к данным (Entity Framework Core)
│   ├── Db.cs               # Фабрика подключений. Читает connection.txt и создает PhotoContext.
│   └── PhotoContext.cs     # Контекст базы данных (сгенерирован командой dotnet ef dbcontext scaffold).
│
├── Models/                 # Модели данных (классы-обертки над таблицами SQL Server)
│   ├── Hall.cs             # Модель зала (id, name, image_path, equipment_description...) [Scaffold]
│   ├── Order.cs            # Модель заказа (client_id, hall_id, date, hours_count...) [Scaffold]
│   ├── Photographer.cs     # Модель фотографа (name, price_per_hour...) [Scaffold]
│   ├── Role.cs             # Справочник ролей пользователей [Scaffold]
│   ├── Status.cs           # Справочник статусов заказов [Scaffold]
│   ├── User.cs             # Модель пользователя системы [Scaffold]
│   └── ModelExtras.cs      # Partial-классы для расширения моделей:
│
├── Services/               # Вспомогательные классы уровня сервиса (без логики БД пока)
│   └── AppException.cs     # Класс ошибки с понятным текстом для пользователя.
│
├── Views/                  # Интерфейс пользователя (Avalonia UI / XAML)
│   ├── UiSupport.cs        # Технический помощник для интерфейса:
│   ├── MainWindow.axaml    # Главное окно приложения (пока содержит только стандартный шаблон "Welcome to Avalonia").
│   └── MainWindow.axaml.cs # Кодbehind главного окна (пустой или минимальный).
│
├── App.axaml               # Глобальные ресурсы и стили всего приложения:
├── App.axaml.cs            # Точка входа XAML-части (InitializeComponent, Startup).
├── Program.cs              # Точка входа C# (Main метод, создание Builder, запуск Run<T>).
├── connection.txt          # Файл конфигурации подключения к SQL Server.
└── Photo.csproj            # Файл проекта .NET (ссылки на NuGet пакеты: Avalonia, EF Core, SqlClient).
